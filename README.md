# RH Zone Gaming Store

A static, responsive gaming e-commerce storefront.

## Run Locally

Open PowerShell in this folder and run:

```powershell
.\start-server.ps1
```

Or double-click:

```text
start-rh-zone.bat
```

Then open:

```text
http://localhost:8090/
```

You can also open `index.html` directly, but the local server keeps browser previews stable.
